# Process Overview

This area explains how documentation is structured, discovered, maintained,
and kept consistent in this repository.

It exists so humans and agents can find the smallest useful set of docs,
understand how those docs should be used, and keep the docs tree synchronized
as repository truth changes.

Read the focused docs here for routing, the indexed docs system, transitional
states, co-located docs, terminology maintenance, or Markplane tracking. Read
`conceptual-simplicity.md` when a task affects boundaries, decomposition,
terminology, or docs structure.
